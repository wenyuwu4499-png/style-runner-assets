# Style Runner | Seongsu Basic EN | IMWEB V8

獨立新小工具，請勿覆蓋現有上線版本。使用 IMWEB Custom Widget Studio：

1. 開啟 01_HTML.txt，複製全文至 HTML 分頁。
2. 開啟 02_CSS.txt，複製全文至 CSS 分頁。
3. 開啟 03_JS.txt，複製全文至 JavaScript 分頁。
4. 開啟 04_VARIABLES.json，複製全文至 變數(변수) 分頁。
5. 儲存後，回到 Design Mode 設定每張圖片與 Review 文字；在網站「預覽」測試，再發布。

設計：
- Hero、4 項資訊、痛點與圓形照片、Why Seongsu 2 Point、9 張穿搭長圖（每張單獨一列）。
- 9 張 Review：各自包含可上傳圖片、可修改重點大標、可修改內文、可修改國籍/名字/來源。
- Review 雙排橫向捲動，約每 5 秒向右自動輪播；左右按鈕、觸控與暫停。
- 100+、70+、4.9★ 統計動態，請在上線前核對實際數據。
- 活動欄位未有可核對正式名稱，因此使用「Korea Tourism Event / Participation details pending」占位；請更新為真實活動後再上線。
- Desktop Sticky 預約卡；手機文章底部保留完整卡片，另外提供固定底部 Book Now（右側約 86px 留給客服按鈕）。
- 預約 URL 預設為 Bokun 單人 Basic 商品 1321544，價格顯示 $60 USD，請確認正式價格。
- 原 Review 英文內文為客人提供圖片的濃縮摘要，不是逐字引文；五星與國籍請依原始憑證核對。
- 程式已做靜態對照檢查（HTML/CSS/JS 各低於 IMWEB 10,000 字元、圖片欄位 25 個、9 筆評論、變數全對應），尚未在你的 IMWEB Design Mode 實測。
- 長圖仍須符合 IMWEB 圖片上傳限制，若照片尺寸過大請使用已切好的片段。
